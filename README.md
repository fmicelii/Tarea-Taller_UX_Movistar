# RecetApp — Benchmark de aplicaciones de recetas

Proyecto de Taller UX, Accesibilidad e Inteligencia Artificial (UTN.BA). El benchmark compara Supercook, Cookpad y Gronda para detectar patrones y oportunidades aplicables a RecetApp: ayudar a elegir qué cocinar con los ingredientes disponibles y generar una lista de compras con lo que falta.

## Estructura

- `index.html` y `styles.css`: página web del benchmark.
- `supercook`, `cookpad` y `gronda`: notas de campo y capturas de cada aplicación.
- `memoria_del_proyecto_benchmark.md`: contexto, criterios y pautas de análisis de la cátedra.

## Cómo usar

1. Abrir `index.html` en un navegador. No requiere instalación ni servidor.
2. Completar `anotaciones.txt` durante la evaluación de cada app y guardar la evidencia visual en su carpeta `screenshots`.
3. Actualizar la tabla y las conclusiones del HTML únicamente con observaciones verificables de las notas y capturas.

## Registro de evidencia

Para cada tarea, anotar el punto de inicio, los pasos/taps, el tiempo medido, los textos literales, el resultado y la evidencia asociada. Registrar también dispositivo, sistema operativo, versión de la app, fecha e idioma/región: estos datos permiten interpretar y repetir la observación.

La tabla comienza deliberadamente como “Pendiente de relevar”. No presenta hipótesis como resultados. Evitar juicios subjetivos; describir conductas observables, cantidades, estados y textos de interfaz. Si un criterio no se pudo comprobar, indicarlo como tal en lugar de inferirlo.
